# Decision app — native demo
Prototype 06 HTML (SHA-256 63d371dd3c83f37c9bbc29e7f2c7b9e69fd863e00b73221c8c2056315a85fba7), compact local record storage, eight exports. No actual purchases: ¥100 / $1 / €1 are intended regional prices. Android SDK build and iOS simulator/unsigned device build are isolated CI jobs. This draft is not an app-store release, has no personal records, no network service, and does not alter the ERG kernel. Android uses WebViewAssetLoader (no INTERNET permission) and user-selected Documents import/export; iOS uses local WKWebView, native atomic file storage and share sheet. Device execution and real billing not validated. The app is an optional recommendation, never a guarantee or instruction to obey. Formal bindings reference historical proofs; this app is not Lean-verified.

# 目的に必要な観測だけを残す有限実験

R005 の候補 `cand.f0.period_bound` を使い、AI に渡す判定表を縮約する。今回の問いは「この軌道に、記録された定理を適用して周期の上限を主張できるか」。元の発話、候補、Lean 宣言の対応は [R005 の束縛](../r005/f0_chat.formal_binding.json)の `fb.f0.period_bound` にある。

## 実行

リポジトリ直下で Python 3.11 を使う。最初のコマンドは縮約した表を出力し、次のコマンドはそれを元の表の全入力と照合する。

```bash
goal=examples/goal_projection/f0_period_bound.goal.json
form=$(mktemp)
python tool/goal_projection.py "$goal" > "$form"
python tool/goal_projection.py "$goal" --check "$form"
python tool/goal_projection.py "$goal" --check examples/goal_projection/drop_distinct.form.json
```

最後のコマンドには相異性の条件を落とした表を渡している。終了コードは一致が 0、不一致が 1、入力形式の誤りが 2。不一致の出力には、元のケース ID、観測値、期待した判定と実際の判定が入る。

## 「最小」の範囲

sidecar を作る人が、元の ERG ノード、目的、名前付きの真偽値の観測、全組合せに対する期待結果を書く。変換器は、一つの観測だけを反転して結果が変わる組を探す。そういう組があれば、その観測を落とした表では二つの入力を区別できない。残りの観測は一つずつ反転しても結果が変わらないので、まとめて取り除ける。これにより、**与えた観測の部分集合を使う表の中で、一意の最小集合**が得られる。出力の列名と行順は正規化される。

縮約した表を読むときは、元の sidecar にある目的と前提を共有する。観測がまだ定義されていない自然言語や、一部の真偽値の組合せが実現不能な仕様は、この実験の対象外である。定数の判定は、観測ゼロ個・1行の表で表す。

## 周期上限の例

台集合は有限、$K$ は冪等、$T=\mathrm{step}(K,S,C)$、$p>0$ を固定前提とする。元の3項目から次の2項目が残る。

- `returns_at_p` は、$T^p(x)=x$ か。
- `first_p_distinct` は、$x,T(x),\ldots,T^{p-1}(x)$ がすべて相異なるか。

両方が真なら `covered`、それ以外は `outside_scope`。後者はこの定理を適用するための仮定が欠けているという判定である。今回あえて加えた第3の項目 `starts_at_zero` は、初期点のラベルが 0 かどうかを表す。

相異性を落とすと、1点集合で $K=T=\mathrm{id}$ とし $p=2$ とした場合にも適用可と答える。このとき出発点には戻るが、同じ点を二度数えることになり、結論は $2\leq 1$ になる。

独立検算では $K=\mathrm{id}$ とし、1〜3点の全自己写像、すべての初期点、$p=1,2,3,4$ を列挙する。各軌道を初期点に初めて戻るまで（最大で台集合の大きさまで）たどり、その時刻を直接得る。この方法で全360件を確認でき、定理を適用できるのは58件である。相異性を落とした表は116件、復帰条件を落とした表は108件を余分に適用可と判定する。
